# Shorts · 截图标注工具

跨平台截图标注工具（macOS / Windows），Python + PyQt6 单代码库。区域 / 窗口 / 全屏 / 滚动长截图、GIF 与 MP4 录制、OCR、十余种标注工具。

## 功能

- **区域截图** — 拖拽选区，自动吸附窗口边缘
- **窗口截图** — 鼠标悬停高亮，单击截取整窗
- **全屏截图**
- **滚动截图** — 滚动内容自动拼接成长图（NCC + Sobel 边缘匹配，支持自动滚动模式与滚轮里程计先验）
- **GIF / MP4 录制** — 选区录制，带点击涟漪与录制中标注
- **OCR 文字识别** — macOS 原生 Vision（中英文），识别结果直接复制
- **标注工具** — 箭头、直线（实/虚线）、矩形、椭圆、文字、画笔、高亮、马赛克（块状/高斯）、序号、取色器、标注描边
- 复制到剪贴板 / 保存文件、开机自启、Retina 2x 清晰输出

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

macOS 下 OCR 功能需编译 Swift 辅助程序（已预编译 arm64 二进制；其他架构需自编译）：

```bash
swiftc core/ocr_helper.swift -o core/ocr_helper -O
```

## 快捷键

| 平台 | 全局截图快捷键 |
|------|--------------|
| Windows | Ctrl + Alt + A |
| macOS | 双击 Cmd 键 |

## macOS 权限（首次使用需手动授权）

这个工具深度依赖 macOS 系统能力，首次使用请在 **系统设置 → 隐私与安全性** 中授权：

| 权限 | 用途 | 不授权的后果 |
|------|------|------------|
| 辅助功能 | 全局热键（双击 Cmd）、自动滚动 | 热键不触发；自动滚动无法滚动目标页面 |
| 屏幕录制 | 截图 / GIF / OCR | 截图全黑 |
| 输入监控 | 滚动截图的滚轮里程计 | 滚动拼接退化为纯视觉匹配（仍可用） |

> 提示：开发迭代中频繁重打包会改变 adhoc 签名，macOS 的 TCC 授权可能失效，需在系统设置中把 Shorts 的开关关掉再重新打开。

## 打包

```bash
pyinstaller shorts_app.spec
```

Windows 产出 `dist/Shorts.exe`；macOS 产出 `dist/Shorts.app`（adhoc 签名，本地使用可直接打开；分发需自行签名/公证）。
